一般的な実装、アップグレード、移行作業に役立つ Liferay DXP 向けのチュートリアル、サンプルコード、ツールを、私たちのチームが作成して公開しています。新しいコンテンツは随時追加していきます。

我们的团队针对常见的实施、升级和迁移任务，编写并发布 Liferay DXP 教程、示例代码和工具。新内容将持续更新。

## 🔔 Stay up to date · 最新情報を受け取る · 获取最新信息

- **Follow [@LGSAPAC](https://github.com/LGSAPAC)** to see new repositories in your GitHub feed.<br>
  フォローすると、新しいリポジトリが GitHub のフィードに表示されます。<br>
  关注后，新的代码库会显示在您的 GitHub 动态中。
- **Watch** repositories you're interested in (**Watch → Custom → Releases**) to be notified of updates.<br>
  リポジトリを Watch すると、更新時に通知が届きます。<br>
  关注（Watch）代码库，即可在更新时收到通知。
- **Star ⭐** repositories you find useful.<br>
  役に立ったリポジトリには Star を付けてください。<br>
  为有用的代码库加上星标。
